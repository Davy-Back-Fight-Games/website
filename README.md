# Davy Back Fight Games website

Interactive studio landing-page proof of concept built with Vite, TypeScript, and Three.js.

## Development

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

Pushes to `main` build and deploy the site through `.github/workflows/deploy-pages.yml`.
The project is configured for:

`https://davy-back-fight-games.github.io/website/`

In the GitHub repository, open **Settings → Pages** and select **GitHub Actions** as the deployment source.
